Manual das telas

O que cada tela faz, que decisões ela pede e onde as pessoas tropeçam — com imagens da aplicação. O rótulo do campo você lê na tela; o motivo da escolha, não.

Referência das funções

O que dá para chamar em cada tela de código. São sete lugares onde se escreve Python, e o que existe difere em cada um — quem aprende db_query() num Workflow e repete numa ferramenta de Agente recebe NameError.

Instalação

Colocar a plataforma no ar no Linux, Windows ou macOS.

Sobre esta documentação ​

A referência das funções é gerada a partir do código-fonte — dos mesmos construtores de escopo que a plataforma usa para executar. Uma operação nova aparece aqui sem ninguém precisar lembrar dela; uma removida some. Não há uma lista escrita à mão para envelhecer.

As imagens do manual são capturadas da aplicação por um roteiro automatizado, sobre dados semeados. É o que faz cada release ter as telas da versão que ela descreve, em vez de imagens que envelhecem em silêncio.
