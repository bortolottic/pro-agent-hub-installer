On this page

Install ​

The full installation guide — requirements, ports, and the step-by-step for Linux, Windows and macOS — lives in the installer's public repository, which is also where the script is downloaded from:

github.com/bortolottic/pro-agent-hub-installer

Why it is not reproduced here ​

That repository's README is the canonical version: it is what install.sh references and what people already have bookmarked. Copying its 596 lines over here would create a second version to keep in sync — and the second version is always the one that goes stale.

The gist, in one line ​

The platform runs on Docker Swarm. You need Docker installed, Swarm active (docker swarm init), and to run the installer; it brings every service up and prints the address to open.
